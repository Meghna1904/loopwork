# Loopwork

A laptop-first crochet pattern companion prototype. It parses common round instructions, lets you review and edit them, and tracks progress by operation or output stitch. Projects and progress are saved in your browser. Projects can be deleted from the sidebar after a confirmation step.

## Run locally

Requires Node.js. No package installation is needed.

```powershell
npm run dev
```

Open <http://127.0.0.1:4173> in your browser. Data is stored in that browser's local storage.

The first open starts with an editable sample project. Use **Edit pattern** to paste another pattern or build rounds manually.
